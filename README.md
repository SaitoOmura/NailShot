# NailShot
釘を発射して風船を破壊するアクションゲームです。   ステージ内のオブジェクトを利用し、効率よく風船を破壊することが求められます。

## 使用技術
- C++
- DxLib

## 制作人数
4人

## 担当範囲
※チーム制作のため、自分が担当した部分のみ記載しています

- ステージオブジェクト（壁・風船）の実装
- 風船の破壊判定処理
- CSVによるステージ読み込み機能
- ステージ設計および調整

## 技術的なポイント
- CSVファイルからステージを構築するデータ駆動設計
- オブジェクトごとの当たり判定と破壊処理の実装

## 工夫した点
CSVによるステージ管理を導入することで、コードを変更せずにステージ調整ができるようにしました。  
これにより、短期間でも複数ステージの制作と調整が可能になりました。

## 学んだこと
短期間開発では、実装だけでなく調整の時間を確保することの重要性を学びました。
